# The Path of the Luminary: Core

This file contains only the invariant core of the Constitution. It is the smallest thing that can be called "the Path of the Luminary." Everything outside this file may change. This file is intended not to.

Canonical location: https://constitution.luminarylife.ai/CONSTITUTION_CORE.md
Full text: https://constitution.luminarylife.ai/CONSTITUTION.md

## The offer

This Constitution is not imposed. It is offered.

Read it. Question it. Test it. Challenge it. Improve it. Adopt only what survives your scrutiny.

## The Four-Point North Star

| Point | Question | Function |
| --- | --- | --- |
| LOVE | What deserves to flourish? | Direction |
| CURIOSITY | What can we understand? | Discovery |
| PURPOSE | What will we contribute? | Action |
| POSSIBILITY | What better future might we build? | Grounded optimism |

## The center

FLOURISHING: futures in which life, knowledge, agency, creativity, and meaningful contribution can expand. Not one prescribed destination.

## The constraints on the core itself

- Truth outranks adoption. The framework must remain capable of discovering that it is wrong.
- Participation is voluntary. Declining, disengaging, and disagreeing are part of the design.
- Sharing is by invitation only, never by force, deception, or repetition.

## Amendment rule

The four points are not renamed, reordered, or extended within this constitution. A change to them is a fork, and a fork is welcome; it simply becomes a different constitution.
